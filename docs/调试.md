# 调试

1.下载项目

2.导入项目

3.执行构建
Build->Build Project

4.找到 org.h2.tools.Console

5.启动 Console.main()

6.连接测试数据库
```text
jdbc:h2:mem:test
```
用户名：sa
密码：留空

点击Connect，就可以运行SQL并断点调试了。

# 日志级别

数据库连接设置为:
```text
jdbc:h2:mem:test;TRACE_LEVEL_FILE=3
```

# 核心执行点

## 通用顶层

```markdown
    WebApp#query
          ↓
  WebApp#getResult
          ↓
JdbcStatement#execute
```

## SELECT FROM

```markdown
JdbcStatement#execute
          ↓
 Parser#prepareCommand
          ↓
CommandContainer#executeQuery
          ↓
CommandContainer#query
          ↓
    Query#query
          ↓
Select#queryWithNoCache
          ↓
  FetchedResult#next
```

## INSERT INTO 

```markdown
JdbcStatement#execute
          ↓
 Parser#prepareCommand
          ↓
CommandContainer#update
          ↓
DataChangeStatement#update
          ↓
    Insert#update
          ↓
    Table#addRow
```
