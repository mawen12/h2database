# H2 源码总览

**主包路径：org.h2.***

## 核心模块

|  模块 | 说明 |
|-----| --- |
| org.h2.engine | 数据库引擎核心类，如 Session、Database、ConnectionInfo |
| org.h2.command | SQL 解析器和执行计划生成器（含 DML/DQL/DCL） |
| org.h2.expression | SQL 表达式抽象，如函数、比较、算术表达式 |
| org.h2.table | 表的定义和数据访问逻辑，如 Table、TableScan、Index |
| org.h2.mystore | 存储引擎，主要是基于 MVStore 的文件存储 |
| org.h2.result | 查询结果处理（ResultSet、ResultTarget）等 |
| org.h2.value | 所有数据类型的封装，比如 ValueInt、ValueString 等 |
| org.h2.index | 索引相关的接口与实现（如 BTree、ScanIndex） |
| org.h2.jdbc | JDBC 层封装，面向外部暴露的接口 |


## 源码阅读建议

**1.从 org.h2.Driver 入手**

这是 JDBC 的入口，了解如何从外部连接 H2。

**2.跟踪 SQL 执行流程**

比如执行 SELECT * FROM user 时，流程大致如下：

```java
org.h2.Driver.connect()
-> Session.prepareCommand()
-> Command.executeQuery()
-> Parser.parseSelect()
-> Select.query()
-> TableFilter / Index lookup
-> ResultTarget addRow()
```

**3.关注 MVStore 的持久化实现**

如果对 MVCC 和底层存储感兴趣，可以研究：

- org.h2.mvstore.MVMap
- org.h2.mvstore.MVStore
- org.h2.mvstore.Page (B+Tree 节点)



## 学习目标建议

| 目标                        | 涉及模块                              |
| --------------------------- | ------------------------------------- |
| SQL 解析与执行计划          | org.h2.comamnd<br />org.h2.expression |
| 存储引擎（MVStore）         | org.h2.mvstore                        |
| 表和索引结构                | org.h2.table<br />org.h2.index        |
| JDBC 层理解                 | org.h2.jdbc                           |
| 表达式计算（如 WHERE 条件） | org.h2.expression                     |
